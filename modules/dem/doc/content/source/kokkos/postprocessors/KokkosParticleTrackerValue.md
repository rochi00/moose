# KokkosParticleTrackerValue

!syntax description /Postprocessors/KokkosParticleTrackerValue

Reports one of the counters of a [KokkosParticleTracker.md]: the number of particles, the number
lost, the number migrated between ranks in the last step, or the maximum number of face hops any
particle took in the last step. All values are global across ranks.
